# Changelog

## Unreleased

### 变更

- 主窗口恢复“待审批 / 历史 / 日志”三个 tab，作为主要信息面板
- 标题栏只保留“状态 / 部署 / 设置”三个面板按钮，并与“隐藏到托盘”放在同一行压缩空间
- 状态面板改为覆盖在主窗口上的模糊模态：只保留服务/接入/队列状态、连接凭证和运行诊断
- 新增独立“部署”入口：本机接入与远程服务器部署以并列卡片呈现，各自带状态和操作，不再把服务端部署混在状态面板里
- 部署界面去掉 01/02/03 这类数字标号，改为图标、标题、状态和说明引导
- 设置面板改为模糊模态，并把“提醒方式”收进设置的“提醒”分类（位置、焦点、本机模式、超时回退）
- 移除独立“控制台”窗口，所有二级页面都在主窗口内以模态打开；托盘提供“状态…”和“部署…”入口，`⌘/Ctrl + ,` 仍可直接打开设置

## 0.3.0 — 2026-10-23

### 新增

- 多会话弹窗新增会话身份条：项目头像、稳定短码（session_id 前 4 位）、主机/终端/分支/短路径、任务摘要
- 钩子上报 `task` / `branch`：审批钩子与 Stop 通知钩子从 `transcript_path` 提取最近一条用户任务，读取 `.git/HEAD` 获取当前分支；钩子版本升到 7
- 新会话默认用第一条任务摘要命名（22 字），`/new` 产生新 `session_id` 时会获得新名字；同一会话内换主题只更新任务行，不重命名
- 没有任务摘要时按同项目等待会话编号（`项目 #1`、`项目 #2`），自定义命名优先；旧会话不会把编号顶到 #3
- 会话条改为两行（名称 + 任务摘要），当前会话带会话色脊/底色；队列按会话分组并显示任务摘要
- 弹窗支持 `⌘/Ctrl + 1–9` 跨会话切换、`⌘/Ctrl + ↑/↓` 在本会话多条请求间切换；点击会话名可直接重命名（预填任务摘要）
- 系统通知、托盘菜单、完成弹窗同步显示会话名与任务摘要
- 弹窗倒计时支持“暂停/继续”：暂停时冻结服务端超时和进度条，方便在问答场景慢慢打字；会话条和队列同步显示“已暂停”
- 钩子进程增加 600 秒暂停预算（hook 版本 7）；暂停超出预算或关闭应用仍会回退终端

### 测试

- 单元测试 132 个；新增会话身份、首条任务命名、`/new` 场景、服务端暂停/恢复回归
- 真实 Claude E2E：双会话用例断言任务摘要、会话名与短码互不相同；timeout 用例暂停 6 秒后确认仍 pending，恢复后正常回退
