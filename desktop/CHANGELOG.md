# Changelog

## 0.6.2 — 2026-10-25

### 修复

- 完成通知弹窗出现时不再"从高到低逐步收缩"（约 650ms 到稳态）。两个叠加原因都已消除：
  - 首次高度上报发生在通知帧上屏之前：主进程 reveal 窗口的瞬间，屏幕上还是上一张（更高的）审批卡帧，闪现 1–3 帧后才被通知帧替换。现在首次上报等待两帧（double-rAF，120ms 兜底），保证 reveal 时通知帧已在屏上
  - 完成通知卡片此前共享审批卡的 `max-height: calc(100vh - 36px)`（border-box）：窗口每次 resize 都把卡片夹紧 2px，重新测量的高度又比窗口矮 2px，形成每帧 −2px 的下降螺旋，直到撞到 300px 窗口下限（探针实测 760 → 377 后一路降到 300，共 39 步）。通知内容短且不滚动，改为 `max-height: none`，测量一步收敛
- 触发条件说明：通知内容（任务/正文）较高（自然高度 > 300px）时必现螺旋；此前 demo 文案短（299 < 下限）所以未暴露

### 测试

- `pnpm typecheck`、`pnpm test`（182）、`pnpm self-test`、`pnpm build` 通过
- 修复验证：CDP 逐帧跟踪隔离实例的 Stop 通知，窗口高度 760 → 377 一步到位后恒定，无螺旋；对比修复前 377 → 300 每帧 −2px
- 真实 Claude E2E：`stop`、`multi`（双会话并发、会话条切换、逐条批准）、`timeout` 通过；`resolved` 因当次会话未暴露工具按脚本逻辑 SKIP；`bypass` 的 claude 进程 120s 零输出被当次路由模型阻断（`work-bypass.out` 为空，与 0.6.1 时同类，详见 `E2E.md`）

## 0.6.1 — 2026-10-25

### 变更

- 审批弹窗信息层级重构：当前任务作为 H1，会话名降为身份行；不再用 `item.message`（工具消息/命令）冒充标题
- 命令/工具名只出现一次；风险、超时回退、稍后提醒各收敛为一处；倒计时只保留一个剩余时间数字，“按历史约需”放进 tooltip
- 决策背景前置：工作目录贴近命令、已等待时长、此前允许/拒绝次数、相同请求合并与跨会话提示
- 工具动词化：Bash/Edit/Write/WebFetch/ExitPlanMode/MCP 使用不同内容标题和主按钮（允许执行 / 允许修改 / 允许写入 / 允许访问 / 批准计划 / 允许调用）；“交给终端”改为“在终端处理”
- 问答模式：当前任务仍是 H1，问题只出现一次；未知工具从 `toolInput` 提取 description/prompt/query 摘要，不再只显示工具名
- 长期授权收敛：Claude Code 权限建议与“记住此命令”收进“更多授权方式”折叠面板，主操作只保留允许/拒绝/在终端处理
- 会话条恢复任务行；任务与会话名相同时自动隐藏重复行；活动会话与身份条不再重复展示同一个名称
- 长命令支持“展开全部命令”，避免危险参数藏在 150px 滚动区
- 可访问性：标题变更后补 `aria-describedby`；帮助按钮 24px；关键元数据从 9–10px `--faint` 提升到 11px `--muted`
- 审批操作按钮改为紧凑等宽（144px）并居中；快捷键徽标固定在左侧、标签独立居中，不再被徽标挤偏；完成通知的“知道了”仍保持全宽
- hook v9：任务摘要跳过“继续 / 好的 / ok”等纯确认词；审批钩子新增 `intent`（最后一条 assistant 文本）作为“为什么现在做这次操作”的背景

### 修复

- 完成通知弹窗不再先按上一张审批卡的高度显示、再缩到通知高度：切换为通知时先隐藏旧卡片，等通知渲染并上报真实高度后再显示；同时移除 500ms 兜底显示，避免渲染慢时兜底先把旧卡片露出来，只剩“测量完成后一次性出现”
- Windows CI：hook 测试的 Python 输出改为 ASCII JSON，避免 Windows 默认 cp1252 编码无法输出中文导致测试失败

### 测试

- `pnpm typecheck`、`pnpm test`（182）、`pnpm build` 通过；`pnpm capture` 已重新生成高风险/多会话/暂停/问答/回退/更多授权/完成通知截图
- 新增工具动词、未知工具摘要、历史决策计数、等待时长、确认词过滤、assistant intent 的回归测试
- 真实 Claude E2E（分轮定向）：`stop`、`multi`、`resolved`、`timeout` 均至少一次通过；`multi` 在最终代码上复跑 `E2E PASS · multi · 24.3s`。全量 `bypass` 仍被当次路由模型的 `unrecognized_model` 阻断，详情见 `E2E.md`

## 0.6.0 — 2026-10-25

- 规则建议：连续允许同一命令后提示固化规则；弹窗支持“仅本会话 / 本项目”范围、有效期和匹配预览
- 拒绝理由快捷 chips；AskUserQuestion 的 Enter 改为下一道未答题，`⌘←/→` 切题
- 弹窗 `×` 改为“收起”（保留审批和倒计时，超时前 15s 自动重现）；“交给终端”保留显式入口

- diff 摘要（文件数 / +N / −N）与超长 diff 折叠；决策区固定在卡片底部，长内容滚动时按钮始终可见
- 通知显示最早截止时间、点击直达具体请求；macOS 通知增加“打开”动作；托盘显示组数/条数与最早截止
- badge 改为按决策组计数，tooltip 保留“N 组 / M 条”明细

### 变更
